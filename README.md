# Taylor edding

An experimental artist website with parallax, release artwork, a Bandcamp player, and artist links.

## Deploy to Vercel

Import this repository. Choose **Other** as the framework, leave the build command empty, and use **dist** as the output directory. The included vercel.json configures the output directory.

## Edit

- `dist/index.html`: content and structure
- `dist/style.css`: visual design and responsive styles
- `dist/app.js`: interactions and motion
- `dist/assets/`: artist and release images

No dependencies, environment variables, or database are required. The music player uses Bandcamp's hosted embed. Artwork and music belong to their respective rights holders.
